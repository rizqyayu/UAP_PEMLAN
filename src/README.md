# Rembulan Mart

Rembulan Mart merupakan aplikasi kasir berbasis desktop yang dikembangkan menggunakan bahasa pemrograman Java.
Aplikasi ini dibuat untuk membantu proses pengelolaan data barang serta transaksi penjualan secara sederhana.

## Fitur Aplikasi
- Login Admin
- Tambah Data Barang
- Lihat dan Kelola Data Barang
- Transaksi Kasir
- Penyimpanan Data Menggunakan File Teks

## Teknologi yang Digunakan
- Java SE
- Java Swing
- Java AWT
- Java IO
- Java Util

## Cara Menjalankan Aplikasi
1. Pastikan JDK sudah terinstall.
2. Jalankan file `RembulanMart.java`.
3. Login dengan username *admin* dan password *12345*.
